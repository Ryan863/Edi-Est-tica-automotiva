# EDI Estética Automotiva - Website Oficial

Website moderno de alta performance desenvolvido para a **EDI Estética Automotiva**, inspirado na estética visual *Dark Studio de Luxo* com iluminação técnica em azul ciano, acabamento espelhado e foco em conversão.

![EDI Estética Automotiva](assets/images/hero_sports_car.jpg)

---

## 🌟 Principais Recursos

- **Visual Dark Studio & Efeitos Neon:** Design inspirado em estúdios de estética de alto padrão, com ambient glow e glassmorphism.
- **Simulador de Orçamento Interativo:**
  - Seleção por categoria de veículo (Hatch, Sedan, SUV, Picape/Grande).
  - Cálculo instantâneo com base nos serviços escolhidos.
  - Envio direto para o WhatsApp oficial **(49) 98844-9865** com mensagem pronta e personalizada.
- **Slider Antes & Depois Interativo:** Controle deslizante para comparação de correção de pintura e vitrificação 9H.
- **Localização no Google Maps:**
  - Mapa interativo embedado (Herval d'Oeste - SC).
  - Botões diretos para traçar rota no **Google Maps** e no **Waze**.
  - Função de copiar endereço completo com confirmação visual (toast).
- **Status Operacional em Tempo Real:** Indicador dinâmico de estúdio aberto/fechado conforme horário atual.
- **Segurança Web Básica:**
  - Content Security Policy (CSP) contra ataques XSS.
  - Sanitização de inputs do usuário.
  - Proteção anti-spam por campo Honeypot.
  - Rate limiting contra cliques repetidos.
  - Links externos protegidos com `rel="noopener noreferrer"`.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Semântica avançada e acessibilidade.
- **CSS3 Puro:** Custom properties, grid, flexbox, backdrop-filter e animações suaves.
- **JavaScript Moderno:** Vanilla JS modular sem dependências pesadas externas.
- **Google Fonts:** Tipografia *Outfit* e *Plus Jakarta Sans*.
- **Font Awesome:** Ícones vetoriais modernos.

## 🚀 Como Executar Localmente

Você pode abrir o arquivo `index.html` diretamente em qualquer navegador moderno ou rodar um servidor local:

```bash
# Com Python 3
python -m http.server 8080

# Ou com Node.js npx serve
npx serve
```

Acesse em: `http://localhost:8080`
